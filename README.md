# HsPAC
PacMan rewritten in Haskell for an assignment

# Running this 
Requirements:
- GHC
- Cabal

Install GHC and Cabal using GHCup:
https://www.haskell.org/ghcup/

Running:
1. Open a terminal in the project root.
2. Run:

   cabal run
